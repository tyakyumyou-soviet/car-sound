# 86 ZN6 バックタービン音シミュレーター

Mac上で車両操作を再現し、OBD2から届く想定の車両データを使って、アクセルオフ時にバックタービン風の音を鳴らすPythonプロトタイプです。

## 起動

初回セットアップ済みです。次のコマンドで、プロジェクト専用のPython 3.11環境から起動します。

```bash
./run.command
```

Finderから `run.command` をダブルクリックしても起動できます。ローカル操作画面がブラウザで開きます。音は `miniaudio` からmacOSのCore Audioへ直接、約12 ms単位で連続送信します。エンジン音とフラッター音は実録素材を使います。終了はターミナルで `Control+C` を押します。

## 操作

| 操作 | キー |
|---|---|
| アクセル | `↑` / `W`（押している間） |
| ブレーキ | `↓` / `S`（押している間） |
| クラッチ | `C`（押している間） |
| ギア | `1`〜`6` |
| ニュートラル | `N` |
| アクセルを一気に戻す | `Space` |
| 終了 | `Esc` |

画面内のアクセルスライダー、クラッチ、ブレーキ、ギアボタンでも操作できます。Nから1速へ入れて発進し、回転が上がったらクラッチを踏んで2速へ。3,000 rpm以上・正圧までブーストを溜めた後、急にアクセルを戻すと音が出ます。

## 構成

```text
操作/UI -> VirtualVehicle -> OBDFrame -> BackTurboDetector -> SoundEngine
                         将来: 実車OBD2入力 --^
```

- `VirtualVehicle` は車重、タイヤ半径、ギア比、回転数別トルク、空気抵抗を用いて、速度・回転数・ブーストを約60 Hzで滑らかに計算します。
- UI以降は `OBDFrame` だけを見るため、実車対応時はデータ入力部分を差し替えられます。
- `BackTurboDetector` は高回転・加圧状態からの急なアクセルオフ、またはクラッチ操作を検出します。
- `SoundEngine` はGT-86/BRZの実車ダイノ録音から回転数別のループを作り、隣接帯を連続的に混ぜます。アクセルオフ時は、低圧なら短い「ポウ」、中圧なら空気音中心の「プシュー」、高圧なら実録の多段フラッターを鳴らします。途中でアクセルを踏み直すと約25〜45 msで消えます。

## 実車化するときの注意

ZN6の一般的なOBD-II PIDだけで取りやすいのは回転数、車速、スロットル開度などです。クラッチスイッチや現在ギアは標準PIDに存在しない場合があり、CANフレームの解析、ECU固有PID、または速度と回転数からのギア推定が必要になります。実車接続は読み取り専用から始め、運転操作を妨げない電源・配線・音量にしてください。
